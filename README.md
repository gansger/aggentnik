# Аггентник

Панель для Raspberry Pi: перетаскиваешь архив с сайтом в браузере на Windows, а малина сама его распаковывает, ставит зависимости, собирает и запускает. В панели видно состояние сайта, журналы и ссылка на него.

## Установка

Подключись к малине и выполни одну команду:

```bash
ssh -t pi@raspberrypi.local 'curl -fsSL https://raw.githubusercontent.com/gansger/aggentnik/main/install-docker.sh | sudo bash'
```

Установщик спросит домен, почту, порт панели и нужен ли VPN, при необходимости поставит Docker, соберёт образ и запустит панель. В конце он покажет адрес и пароль. Пароль показывается один раз. Для работы команды репозиторий должен быть публичным.

Если указан домен:

1. У регистратора создай A-запись на внешний адрес малины. Установщик проверит её и предупредит, если адрес не совпадает.
2. На роутере проброси на малину порт 80 и порт панели, по умолчанию 7700. Порт 80 нужен для выдачи и продления сертификата.

Сертификат получает и продлевает контейнер Caddy. Пустой ответ на вопрос о домене запускает панель по HTTP для домашней сети.

Первая сборка образа на малине занимает 10–20 минут. Повторный запуск той же команды обновляет панель или меняет домен: сайты, пароль и настройки сохраняются. Если на малине уже стоит панель без Docker, установщик предложит её перенести. Она работает, пока образ собирается, а её службы отключаются только после успешной сборки. Сайты с Python и собранными зависимостями Node.js после переноса нужно один раз пересобрать кнопкой «Пересобрать».

### Что запускается

| Контейнер | Зачем | Права |
| --- | --- | --- |
| `panel` | Панель и все сайты | Обычный пользователь, файлы малины ему недоступны, кроме `/var/lib/malinnik` |
| `caddy` | HTTPS и сертификат, только при указанном домене | Обычные |
| `vpn` | Сервис VPN, только если он включён | **Полные права на малине.** Без них `awg-quick` не настроит маршруты. Внутри только `vpn_helper.py` |

Данные лежат на самой малине, а не внутри контейнеров: `/var/lib/malinnik` (сайты, настройки), `/etc/amnezia/amneziawg` и `/var/lib/malinnik-vpn` (ключ VPN). Сертификаты лежат в томе Docker `aggentnik_caddy-data`.

### Команды

Выполняй их на малине из папки `/opt/aggentnik`.

```bash
sudo docker compose ps
```

```bash
sudo docker compose logs -f panel
```

Сменить пароль:

```bash
sudo docker compose exec panel python3 -m malinnik set-password && sudo docker compose restart panel
```

Запасной вход, если панель недоступна по домену (порт 7699 есть только при установке с доменом): выполни с компьютера команду ниже и, пока она работает, открой `http://localhost:7699`.

```bash
ssh -L 7699:127.0.0.1:7699 pi@raspberrypi.local
```

## Установка без Docker

Выполни в PowerShell из этой папки. Вместо `pi@raspberrypi.local` подставь своего пользователя и адрес малины.

```bash
ssh pi@raspberrypi.local "mkdir -p malinnik-src"
```

```bash
scp -r malinnik install.sh install-amneziawg.sh setup-https.sh pi@raspberrypi.local:malinnik-src/
```

```bash
ssh -t pi@raspberrypi.local "sudo bash malinnik-src/install.sh"
```

В конце установщик покажет адрес панели (`http://адрес-малины:7700`) и пароль. Пароль показывается один раз. Эти же команды обновляют панель: сайты, пароль и настройки сохраняются.

Первая установка занимает несколько минут: AmneziaWG собирается из исходников. Если cloudflared или AmneziaWG поставить не удалось, панель всё равно установится, а эта функция будет недоступна. Запусти установщик ещё раз, когда появится связь.

Сменить пароль:

```bash
ssh -t pi@raspberrypi.local "cd /opt/malinnik && sudo -u malinnik python3 -m malinnik --data /var/lib/malinnik/data set-password && sudo systemctl restart malinnik"
```

Перезапуск завершает уже открытые сессии. Без него вход со старым паролем в открытых вкладках продолжит работать.

## Домен и HTTPS без Docker

В Docker этим занимается установщик. При установке без Docker скрипт `setup-https.sh` получает бесплатный сертификат Let's Encrypt, настраивает его автопродление и ставит nginx на порт 7700. Панель при этом уходит на внутренний порт 7699, недоступный снаружи.

Перед запуском:

1. У регистратора домена создай A-запись на внешний адрес малины и дождись, пока она заработает. Если адрес у провайдера меняется, домен перестанет вести на малину: понадобится статический адрес.
2. На роутере проброси на малину порты 80 и 7700. Порт 80 нужен для выдачи и продления сертификата, без него сертификат перестанет продлеваться.

Запуск, почта необязательна:

```bash
scp -r malinnik install.sh install-amneziawg.sh setup-https.sh pi@raspberrypi.local:malinnik-src/
```

```bash
ssh -t pi@raspberrypi.local "sudo bash malinnik-src/setup-https.sh домен.ru почта@example.com"
```

Запуская скрипт, ты принимаешь [условия Let's Encrypt](https://letsencrypt.org/repository/). Сначала скрипт делает пробную проверку: если домен или порт настроены неверно, панель продолжит работать как раньше. После установки панель открывается по адресу `https://домен.ru:7700`, а по `http://` происходит переадресация.

Сертификат продлевается сам: это делает таймер `certbot.timer`, а после продления nginx перезагружает настройки. Проверить можно так:

```bash
ssh pi@raspberrypi.local "systemctl list-timers certbot.timer; sudo certbot certificates"
```

Что важно знать:

- **Панель останется доступна из интернета.** HTTPS шифрует трафик, но защищает панель только пароль, а через неё можно запустить код на малине. Задай длинный случайный пароль. Попытки входа ограничены и в панели, и в nginx.
- **Обращение по IP-адресу** к порту 7700 nginx отклоняет: панель открывается только по домену.
- **Сайты шифрования не получают.** Они по-прежнему работают по HTTP на портах 8100–8199, и если эти порты проброшены, то доступны напрямую. HTTPS для них даёт кнопка «Опубликовать».
- **HSTS не включён намеренно:** он распространился бы на все порты домена и сломал бы сайты на HTTP.
- **Обновление панели** через `install.sh` эти настройки сохраняет.
- **Панель перестаёт открываться по адресу `192.168.x.x:7700`.** Если из дома домен не открывается, значит, роутер не умеет обращаться к своему внешнему адресу изнутри сети. Тогда добавь в `C:\Windows\System32\drivers\etc\hosts` на компьютере строку `192.168.x.x домен.ru`.
- **Включённый VPN с `AllowedIPs = 0.0.0.0/0` мешает входящим соединениям.** Ответы посетителям из интернета уходят в туннель и не доходят. Пока VPN включён, панель по домену снаружи не откроется, порты сайтов снаружи не ответят, а сертификат не продлится. Из домашней сети панель работает, а опубликованные сайты работают через Cloudflare. Сертификату хватает запаса: продление начинается за 30 дней до окончания срока, поэтому VPN надо хотя бы иногда выключать.

Запасной вход, если панель недоступна по домену: выполни команду ниже и, пока она работает, открой `http://localhost:7699`.

```bash
ssh -L 7699:127.0.0.1:7699 pi@raspberrypi.local
```

Как отключить HTTPS и вернуть панель на прямой порт:

```bash
ssh -t pi@raspberrypi.local "sudo rm -f /etc/systemd/system/malinnik.service.d/https.conf /etc/nginx/conf.d/malinnik.conf /etc/malinnik-https-domain && sudo systemctl daemon-reload && sudo systemctl reload nginx && sudo systemctl restart malinnik"
```

## Как пользоваться

- **Новый сайт:** перетащи архив на страницу. Название берётся из имени файла.
- **Обновить сайт:** перетащи архив прямо на строку сайта или загрузи архив с тем же именем. Порт не меняется.
- **Архивы:** ZIP, TAR, TAR.GZ, 7Z, RAR. Папку нужно сначала упаковать.

Каждый сайт получает свой порт из диапазона 8100–8199 и открывается по адресу `http://адрес-малины:порт`.

## Публикация в интернете

Кнопка «Опубликовать» у сайта открывает к нему доступ через Cloudflare Tunnel: появляется ссылка вида `https://случайные-слова.trycloudflare.com` с HTTPS. Порты на роутере открывать не нужно, аккаунт и домен тоже. Туннель ведёт только на порт этого сайта, панель из интернета недоступна.

Это быстрый туннель, и у него есть ограничения:

- адрес случайный и меняется при перезапуске панели или малины, а новый приходит в Telegram, если он настроен;
- Cloudflare предназначает такие туннели для проб и не гарантирует их работу. Постоянный адрес требует своего домена в Cloudflare, этого панель пока не умеет;
- посетители видят всё, что отдаёт сайт, поэтому проверь его перед публикацией. Для Django добавь адрес в `ALLOWED_HOSTS`. Панель скрывает `.env` и файлы баз только у статических и PHP-сайтов; приложения на Node и Python сами решают, что отдавать.

## VPN

Карточка «VPN AmneziaWG» принимает ключ `vpn://` или содержимое файла `.conf` и включается переключателем. После перезагрузки малины VPN поднимается сам, если был включён.

- **Что идёт через VPN:** если в ключе `AllowedIPs = 0.0.0.0/0`, то весь интернет-трафик малины: запросы сайтов, Telegram и туннели публикации. Опубликованные сайты могут работать медленнее.
- **Домашняя сеть:** панель и SSH из домашней сети продолжают работать. Ключ, который отрезал бы малину от домашней сети, не примется.
- **Доступ извне:** при `AllowedIPs = 0.0.0.0/0` входящие соединения из интернета перестают работать, подробности в разделе «Домен и HTTPS».
- **Команды в ключе:** `PreUp`, `PostUp`, `PreDown`, `PostDown` вырезаются, потому что они выполнялись бы от root.
- **DNS:** на малине без `resolvconf` DNS из ключа не применяется, и панель об этом предупреждает.
- **Ключи платных серверов Amnezia** настроек не содержат: для них нужен файл `.conf`.

Журнал сервиса VPN: `journalctl -u malinnik-vpn`.

## Уведомления в Telegram

Настройка занимает минуту, шаги показаны в карточке: создать бота у @BotFather, вставить токен, написать боту и нажать «Найти мой чат».

Приходят сообщения об упавшем и восстановившемся сайте, результате установки, новом публичном адресе, перегреве, нехватке питания и места на диске, потере связи с сервером VPN и запуске панели. Если связи с Telegram нет, сообщения ждут в очереди до часа; при перезапуске панели очередь теряется.

### Команды бота

| Команда | Что делает |
| --- | --- |
| `/status` | Малина, VPN и все сайты одним сообщением |
| `/sites` | Список сайтов с кнопками |
| `/site имя` | Карточка сайта с кнопками управления |
| `/logs имя` | Последние строки журнала |
| `/restart имя`, `/run имя` | Перезапустить, запустить |
| `/stop имя` | Остановить, с подтверждением |
| `/publish имя`, `/unpublish имя` | Открыть в интернете или снять с публикации, с подтверждением |
| `/vpn`, `/vpn on`, `/vpn off` | Состояние, включение и выключение VPN, с подтверждением |
| `/help` | Справка |

Имя можно не писать: бот предложит выбрать сайт. Хватит и начала имени.

Как бот защищён:

- команды выполняются только из привязанного личного чата и только при включённом переключателе в панели; сообщения из других чатов бот молча игнорирует, в группах команды не работают;
- команды, отправленные более двух минут назад, не выполняются: иначе старый `/stop` сработал бы после включения панели;
- кнопка подтверждения действует пять минут и срабатывает один раз;
- удалять сайты и загружать код через бота нельзя.

Береги токен: с ним нельзя подать команду от твоего имени, но можно читать сообщения, которые приходят боту, и писать от лица бота. В журналах сайта могут быть секреты, и `/logs` отправляет их в Telegram.

У одного бота может быть только одна панель. Если запустить вторую с тем же токеном, панель покажет ошибку.

## Что панель определяет сама

Проверки идут сверху вниз, срабатывает первая подходящая.

| В архиве | Что происходит |
| --- | --- |
| `start.sh` | Запускается `bash start.sh` |
| `index.php`, `public/index.php`, `*.php` | Встроенный сервер PHP |
| `package.json` | `npm install`, `npm run build`, затем `npm start` или раздача `dist`, `build`, `out` |
| `manage.py` | Django: виртуальное окружение, зависимости, `migrate`, `runserver` |
| `app.py`, `main.py` и подобные | Flask через waitress, FastAPI через uvicorn, иначе просто запуск файла |
| `index.html` | Статический сайт, работают и маршруты одностраничных приложений |

Если панель ошиблась или не поняла тип, укажи свою команду в настройках сайта и нажми «Пересобрать». Порт доступен как `$PORT`.

Панель учитывает, что архив собран на Windows:

- убирает `node_modules` и виртуальные окружения: в них файлы под другую систему;
- повторяет установку без `package-lock.json`, если первая попытка не удалась;
- исправляет окончания строк в `.sh`, русские имена файлов из ZIP и кодировку `requirements.txt`;
- убирает из `requirements.txt` пакеты только для Windows, например `pywin32`.

## Что важно знать

**Порт.** Сайт должен читать порт из переменной `PORT`. Если порт задан в коде жёстко, панель его найдёт и покажет верную ссылку, но два таких сайта на одном порту не уживутся.

**Обновления и данные.** При обновлении создаётся новая папка версии, а прошлая остаётся для отката. Из неё переносятся файлы, которых нет в новом архиве: `*.db`, `*.sqlite`, `*.sqlite3`, `.env` и содержимое папок `uploads`, `media`, `data`, `storage`. Если в архиве лежит своя база, она заменит рабочую. Самое надёжное место для данных — папка из переменной `DATA_DIR`: обновления её не трогают.

**Откат.** «Вернуть прошлую версию» возвращает и файлы прошлой версии, включая её копию базы. Изменения, сделанные после обновления, в ней не появятся.

**Сбои.** Если новая версия падает сразу после запуска, панель сама вернёт прошлую. Упавший сайт перезапускается; после пяти быстрых падений подряд попытки прекращаются до ручного запуска.

**Безопасность.**

- Без `setup-https.sh` панель работает по обычному HTTP. В таком виде используй её только в домашней сети и не пробрасывай порт 7700 в интернет.
- Панель запускает код из загруженных архивов. Все сайты работают от одного системного пользователя `malinnik` и могут читать файлы друг друга и самой панели, включая токен Telegram, поэтому загружай только то, чему доверяешь.
- Такой сайт может и обратиться к сервису VPN: включить или выключить VPN либо подменить ключ на свой и пустить трафик малины через чужой сервер. Команды от root он так не выполнит, а приватный ключ не прочитает: он лежит в `/etc/amnezia/amneziawg` и доступен только root.
- У этого пользователя нет прав администратора. Настройки systemd скрывают от сайтов домашние папки и разрешают запись только в `/var/lib/malinnik`. Читать общедоступные файлы системы и выходить в сеть сайты всё равно могут.

## Разработка

```bash
python -m malinnik --data dev-data serve --host 127.0.0.1
```

```bash
python -m unittest discover -s tests
```

Панель написана на Python без внешних зависимостей. Нужен Python 3.9 или новее.

| Файл | За что отвечает |
| --- | --- |
| `malinnik/archive.py` | Распаковка архивов |
| `malinnik/detect.py` | Определение типа сайта |
| `malinnik/sites.py` | Установка, запуск и присмотр за процессами |
| `malinnik/metrics.py` | Показатели из `/proc` |
| `malinnik/tunnel.py` | Публикация через Cloudflare |
| `malinnik/telegram.py`, `malinnik/alerts.py` | Связь с Telegram и выбор, о чём сообщать |
| `malinnik/bot.py` | Команды и кнопки бота |
| `malinnik/vpn.py` | Обращение панели к сервису VPN |
| `malinnik/vpn_helper.py` | Сервис VPN от root, проверка ключей |
| `malinnik/server.py` | HTTP API |
| `malinnik/web/` | Интерфейс |

Данные на малине лежат в `/var/lib/malinnik/data`, журнал самой панели: `journalctl -u malinnik`.
